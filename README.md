# Algorithms and Data Structures

This repository contains a collection of Python implementations focused on practicing and demonstrating various algorithmic and data structure concepts.

## 🚀 Overview

The goal of this project is to strengthen skills in algorithm design, problem solving, and Python coding through hands-on implementation of classic and practical problems.

## 📂 Project Structure

```text
.
├── test/                   # Unit tests and input files
│   └── resources/           # Input files
├── src/                    # Python scripts
│   ├── electric_max_wire_length.py
│   ├── find_if_arr_is_monotonic.py
│   ├── find_min_board_size.py
│   ├── find_min_cable_length.py
│   ├── find_num_of_islands.py
│   ├── finding_indices_of_occurrences_with_KMP.py
│   ├── heap_based_priority_queue.py
│   ├── max_amount_of_experience.py
│   ├── sum_of_tree_depths.py
└── README.md               # Project description
```

## 🧠 Included Topics

- **Heaps & Priority Queues**
- **Dynamic Programming** (e.g., triangle max path)
- **String Algorithms** (KMP pattern matching)
- **Graph Algorithms** (Prim’s algorithm)
- **BFS in 2D Grids** (e.g., counting islands)
- **Binary Trees** (construction, traversal)
- **Geometry-Based Problems** (wire length between pillars)

### ▶️ Run the Script

To run the project, follow these steps:

1. **Clone the repository:**
    ```
    git clone https://github.com/yourusername/algorithms-and-data-structures.git
    cd algorithms-and-data-structures
    ```

2. **Set up your environment (optional but recommended):**

   It's a good idea to set up a virtual environment for managing the Python environment. Run the following commands to create a virtual environment and activate it:
    ```
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

3. **Run the script:**

   To run the `wire_calculator.py` script or any other script, use the following command:
    ```
    python src/wire_calculator.py
    ```

   Make sure to provide the necessary input if the script requires it. You can modify the input files located in the `test/resources` directory, or you may need to pass arguments depending on the script you're running.

### 🧪 Running Tests

To run the unit tests, you can use the following command:

```
pytest test/  # Runs all the tests in the test directory
```
